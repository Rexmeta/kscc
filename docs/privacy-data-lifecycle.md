# 회원 개인정보 생명주기

## 본인 데이터 내보내기

로그인한 본인만 `GET /api/auth/data-export`를 호출할 수 있다. 응답은
`exportVersion: 1`인 JSON 허용 목록 계약으로, 계정 기본정보, 본인 회원사
프로필, 본인이 등록한 행사의 상태·결제 상태·등록일과 행사 요약만 포함한다.
비밀번호 해시, 세션 버전, 권한, 전체 게시물 메타데이터, 다른 회원이나
참석자의 정보는 포함하지 않는다. 계정 ID를 요청 파라미터로 받지 않으므로
타인 ID 조작으로 범위가 바뀌지 않는다.

## 계정 폐쇄 정책

`POST /api/auth/close-account`는 현재 비밀번호와 `계정을 폐쇄합니다` 확인
문구를 요구한다. 폐쇄는 하나의 데이터베이스 트랜잭션에서 처리된다.

- 회원사 프로필은 삭제한다.
- 행사 등록은 참석·정산에 필요한 상태와 시각만 남기고 사용자 ID, 이름,
  이메일, 전화번호, 회사명을 익명화한다.
- 게시물 저자와 설문·번역 변경 이력의 계정 참조를 제거하고 표시명을
  `탈퇴한 사용자`로 바꾼다.
- 문의 답변은 업무상 보존할 수 있도록 답변의 계정 외래키를 유지하되,
  사용자 이름·이메일은 익명 계정 값으로 치환한다.
- 사용자 행은 익명 계정으로 바꾸고 비활성화하며 세션 버전을 증가시킨다.
  따라서 기존 토큰은 즉시 무효화되고 로그인 및 보호 API 접근이 차단된다.

현재 활성 관리자가 한 명뿐이면 계정 폐쇄를 거부한다. 업무상 보존이 필요한
문의 답변·게시물·설문 이력은 별도 자동 삭제 작업의 대상이 아니며, 원문과
연락처의 보존기간 정리는 문의 보존 정책 작업에서 별도로 다룬다.

## 운영 경계

폐쇄 트랜잭션이 중간에 실패하면 데이터베이스 트랜잭션 전체가 롤백되므로
부분 익명화가 남지 않는다. 종료 행사 등록의 운영상 보존 기준은 참석 및
결제 상태와 등록 시각이며, 보존 예외가 변경될 때는 export 허용 목록과
익명화 계약을 함께 검토해야 한다.
